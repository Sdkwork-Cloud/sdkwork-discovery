# Component Specs

This directory is the local SDKWork component contract for `sdkwork-discovery-workspace`.

- Component root: `sdkwork-discovery`
- Canonical standards: `../sdkwork-specs/README.md`
- Machine-readable contract: `specs/component.spec.json`
- Runtime topology contract: `specs/topology.spec.json` (validated via `pnpm topology:validate`)

Read `specs/component.spec.json` before changing public exports, runtime entrypoints, SDK clients, generated artifacts, config keys, or verification commands.
